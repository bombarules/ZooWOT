# Backyard Zoo (WOT)

A phone web app for tracking the animals in your backyard: crows, squirrels, blue jays, cats and more.

## Host it on GitHub Pages
1. Upload every file in this folder (the app, the icons, and the manifests) to this repository.
2. Settings > Pages > Branch: `main`, folder `/ (root)` > Save.
3. Open `https://YOUR-USERNAME.github.io/REPO-NAME/` and add it to your home screen.

## Connect Supabase
1. In Supabase, open SQL Editor, paste `supabase-setup.sql`, and run it once.
2. In the app's Storage tab, enter your project URL and anon key, then tap Connect and sync.

Your Supabase key is saved only on your device, never in this repository.

## App icon
Pick an icon in the app's Storage tab, then use Share > Add to Home Screen. Delete and re-add to change it later.

## App icon
Choose an icon in the app's Storage tab, then add WOT to your home screen (delete and re-add it if it's already there).
